## КЛЮЧОВІ ДОСЛІДНИЦЬКІ ПИТАННЯ

### 1. Загальна тенденція субститованості
> Чи мають досліджувані препарати загальну тенденцію субститованості
> не на 1 локальному ринку, а на ВСІХ досліджуваних локальних ринках?

**Контекст:** Phase 1 дає SHARE_INTERNAL для кожного препарату на кожному ринку окремо. Питання: чи є ці значення консистентними across markets?

### 2. Можливість визначення коефіцієнта
> Чи можна визначити коефіцієнт субститованості препарату,
> виходячи з даних його субститованості з різних локальних ринків?

**Контекст:** Якщо препарат має схожий SHARE_INTERNAL на різних ринках — можна визначити загальний коефіцієнт. Якщо значення сильно варіюються — коефіцієнт ненадійний.

### 3. Методологія розрахунку
> Як правильно розрахувати такий коефіцієнт субститованості?

**Рішення:** Медіана (основна метрика, стійка до аномалій) + зважене середнє (вага = INTERNAL_LIFT) + довірчий інтервал для оцінки невизначеності. Перед розрахунком — IQR outlier detection per drug.

### 4. Статистичні вимоги
> Яким статистичним вимогам повинен відповідати препарат
> для надійного визначення коефіцієнта субститованості?

**Вимоги:**
- Мінімальне покриття ринків (пороги COVERAGE_CLUSTER в `project_core/sub_coef_config/`)
- Прийнятний коефіцієнт варіації (пороги RELIABILITY в `project_core/sub_coef_config/`)
- Очистка від статистичних аномалій (IQR outlier detection)

## БІЗНЕС-ЦІННІСТЬ PHASE 2

### Проблема
Phase 1 дає результати **per market**, але бізнесу потрібні **загальні** рекомендації:
- Чи можна оптимізувати SKU для препарату X **по всій мережі**?
- Чи є препарат Y критичним **для всіх аптек**?

### Рішення
Phase 2 агрегує дані з усіх досліджуваних ринків для визначення **стабільних** патернів субституції.

```
Приклад:
Препарат X на 85 ринках:
├─ SHARE_INTERNAL: 72% ± 5% (VARIATION_COEFFICIENT = 12%)
├─ Висновок: СТАБІЛЬНА субституція
└─ Рекомендація: можна оптимізувати SKU по всій мережі

Препарат Y на 60 ринках:
├─ SHARE_INTERNAL: 45% ± 25% (VARIATION_COEFFICIENT = 55%)
├─ Висновок: НЕСТАБІЛЬНА субституція
└─ Рекомендація: аналізувати індивідуально по регіонах
```

## МЕТРИКИ ТА ІНТЕРПРЕТАЦІЯ

### Основні метрики Phase 2

| Метрика | Формула | Інтерпретація |
|---------|---------|---------------|
| **MEDIAN_SHARE_INTERNAL** | median(SHARE_i) | Основна метрика — типовий коефіцієнт субституції |
| **WEIGHTED_MEAN_SHARE** | Σ(SHARE × LIFT) / Σ(LIFT) | Зважений коефіцієнт (більша вага надійнішим ринкам) |
| **CI_95** | MEAN ± 1.96 × (STD/√N) | Діапазон "справжнього" коефіцієнта |
| **VARIATION_COEFFICIENT** | STD / MEAN (ratio) | Стабільність across markets |
| **MARKET_COVERAGE** | N_markets / TOTAL (ratio) | Репрезентативність даних |
| **RELIABILITY** | На основі VARIATION_COEFFICIENT (пороги в config) | Категорія надійності коефіцієнта |

### Як читати результати

```
MEDIAN_SHARE_INTERNAL = 0.72 означає:
  → Типово 72% попиту залишається в аптеці при stock-out цього препарату

WEIGHTED_MEAN_SHARE = 0.74 означає:
  → Зважений коефіцієнт (більша вага ринкам з більшим INTERNAL_LIFT)

CI_95 = [0.68, 0.76] означає:
  → "Справжній" коефіцієнт з 95% впевненістю в цьому діапазоні

VARIATION_COEFFICIENT = 0.12 означає:
  → Низька варіативність — коефіцієнт стабільний across markets
  → RELIABILITY = HIGH

MARKET_COVERAGE = 0.85 означає:
  → Препарат досліджений на 85% ринків — висока репрезентативність
```

## КЛАСТЕРИЗАЦІЯ ПРЕПАРАТІВ

### За Coverage (COVERAGE_CLUSTER)

Пороги визначені в `project_core/sub_coef_config/coverage_thresholds.py`.

| Кластер | Бізнес-значення |
|---------|-----------------|
| **HIGH** | Достатньо для надійних статистичних тестів |
| **MEDIUM** | Базові висновки можливі |
| **LOW** | Обмежена надійність — обережність у висновках |
| **INSUFFICIENT** | Окремий датасет — недостатньо для висновків |

### За Reliability (на основі VARIATION_COEFFICIENT)

Пороги визначені в `project_core/sub_coef_config/coverage_thresholds.py`.

| Reliability | Інтерпретація |
|-------------|---------------|
| **HIGH** | Стабільна субституція across markets |
| **MEDIUM** | Помірна варіативність |
| **LOW** | Нестабільна — коефіцієнт ненадійний |
| **SINGLE_MARKET** | Один ринок — статистика відсутня, потрібні додаткові дані |

## ОБМЕЖЕННЯ PHASE 2

### Препарати без даних Phase 1

**Проблема:** Phase 1 дає коефіцієнти тільки для препаратів зі stock-out подіями. Решта препаратів не мають даних.

**Рішення:** Ці препарати не включаються в Phase 2 аналіз. Для них потрібне окреме дослідження.

### Препарати з низьким coverage

**Проблема:** Препарати з низьким COVERAGE_CLUSTER (INSUFFICIENT) не мають достатньо даних для надійних висновків.

**Рішення:** Виносяться в окремий датасет для подальшого аналізу або очікування додаткових даних.

## БІЗНЕС-РЕКОМЕНДАЦІЇ

### За результатами Phase 2

| Профіль препарату | Характеристика | Рекомендація |
|-------------------|----------------|--------------|
| HIGH Coverage + HIGH Reliability | Стабільний across markets | Централізовані рішення по мережі |
| HIGH Coverage + LOW Reliability | Різна поведінка по ринках | Регіональна стратегія |
| LOW Coverage | Недостатньо даних | Накопичувати дані, відкладений аналіз |

## ГЛОСАРІЙ Phase 2

| Термін | Визначення |
|--------|------------|
| **Cross-Market Aggregation** | Об'єднання даних з різних локальних ринків |
| **Median** | Основна метрика центральної тенденції, стійка до аномалій |
| **Weighted Mean** | Зважене середнє (вага = INTERNAL_LIFT) |
| **IQR Outlier Detection** | Фільтрація аномальних значень per drug (Q1-k*IQR, Q3+k*IQR) |

| **VARIATION_COEFFICIENT (Coefficient of Variation)** | Відносне стандартне відхилення (ratio) |
| **Confidence Interval (CI)** | Діапазон невизначеності оцінки |
| **Reliability** | Оцінка надійності коефіцієнта (на основі VARIATION_COEFFICIENT) |
